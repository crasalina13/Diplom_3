# Проект с автотестами

Этот проект предназначен для автоматизации тестирования с использованием Java и различных библиотек, таких как Rest-Assured, Selenide и Allure для отчетности.

## Описание

Проект включает в себя набор автотестов, написанных на Java, которые проверяют функциональность API и пользовательского интерфейса. Используются следующие технологии и библиотеки:

- **Java 11**
- **Maven** для управления зависимостями и сборки проекта
- **JUnit** для написания и выполнения тестов
- **Rest-Assured** для тестирования RESTful API
- **Selenide** для автоматизации тестирования веб-приложений
- **Allure** для генерации отчетов о тестировании

## Зависимости

Проект использует следующие зависимости:

- `log4j-slf4j-impl` для логирования
- `rest-assured` для тестирования API
- `lombok` для упрощения кода
- `gson` для работы с JSON
- `junit` для написания тестов
- `selenide` для автоматизации тестирования веб-приложений
- `allure-junit4` и `allure-rest-assured` для интеграции с Allure
